### 2.2 Live Shopping (TikTok & Shopee)

Live Shopping adalah layanan unggulan VidHelp. Berdasarkan data, Live Shopping berkontribusi minimal **80% dari total GMV** brand.

#### A. Dua Mode Live Shopping:

**NON-OBS Live Shopping**
- Device: iPhone (high-end)
- Background: Green Screen + TikTok Filter
- Sudah termasuk: Host, Lighting, Device, Studio, Live Strategy, Report

**OBS Live Shopping**
- Device: Kamera profesional
- Background: Real Green Screen (physical)
- Sudah termasuk: Host, Lighting, Device, Studio, OBS Background, Live Strategy, Report

#### B. Keunggulan OBS vs Non-OBS:

| Aspek | OBS | Non-OBS |
|---|---|---|
| Kualitas Visual | Sangat tinggi (kamera profesional) | Standar tinggi (iPhone) |
| Branding | Professional, lebih premium | Baik |
| Multistream | Ya — TikTok & Shopee bersamaan | Terbatas |
| Background Interaktif | Ya — animated, GIF, sticker, info produk | TikTok filter |
| Solusi Kualitas Shopee 480p | Ya | Tidak |
| GMV Impact | Lebih tinggi berdasarkan data | Baik |

#### C. Fasilitas OBS Production Lengkap:
PC, Microphone, Kamera, Lighting, Studio Set, Greenscreen, Product Display, Virtual Background, Experienced Host, OBS Operator, Free Multi Platform (TikTok & Shopee), Strategy, Data Analyst, Technical & Non-Technical Problem Solving.

#### D. Program 24 Jam Live Shopping:
VidHelp mampu menangani live streaming **24 jam nonstop** untuk beberapa brand sekaligus. Manajemen shift host dilakukan dengan cermat untuk menjaga performa host selalu optimal. Fasilitas istirahat dan dapur tersedia di kantor VidHelp untuk memastikan semua Live Host selalu dalam kondisi prima dan mood yang baik.
